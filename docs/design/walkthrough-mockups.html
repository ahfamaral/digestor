Sample: a 1h 32m interview in Portuguese with an unnamed guest and no date. Click through the steps in order — each one explains what happens behind the scenes.

The pipeline is a LangGraph graph that runs in a background worker. It pauses twice for a human (purple), and its state is saved in Postgres, so a pause can last overnight. Coloured tags show where each capstone tool earns its place.
