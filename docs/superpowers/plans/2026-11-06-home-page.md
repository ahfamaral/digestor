# Home Page (Sessions) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/` becomes a Sessions page listing every ingested video (type tabs, a "needs you" strip, Status and Body filters, a clips strip per row) from which any step opens; the upload form moves to `/new`; the top bar gets a "Sessions" link and, inside a ready session, a clickable stepper.

**Architecture:** One core query returns the session summaries (extended) and one returns clip previews for those sessions; pure functions in `apps/web/lib/home.ts` decide labels, links, counts and filtering (unit-tested); a server page loads the data and a client component renders the table and keeps the filters in the URL query.

**Tech Stack:** Next.js 16 App Router (Cache Components), Drizzle/Postgres, vitest, Tailwind tokens from `globals.css`.

**Spec:** agreed in chat on 2026-11-06 (option B, revised) — the decisions are copied into "Agreed design" below. Mockup (inspiration, not pixels): `.superpowers/brainstorm/7307-1793955375/content/home-scope-b3.html`.

## Agreed design

- `/` = **Sessions** (h1 "Sessions"), a "+ New video" brand button top right linking to `/new`; `/new` shows today's upload page (`UploadForm`) unchanged.
- **Type tabs:** "All" plus one tab per profile that has at least one session, labelled `PROFILES[id].label` with its count. A session with no profile yet counts under All only.
- **Needs-you strip** (four counts; clicking one sets the Status filter): "waiting for your context answers" (`awaiting_context`), "with clips not exported yet" (ready, video not removed, live clips > rendered clips), "failed", "processing now" (any other stage).
- **Filters** (single-select Status chips): Any status · Needs you · Clips to export · Processing · Failed · Ready; toggles: Has clips · Last 7 days (by `createdAt`); search box over titles (case- and accent-insensitive).
- **Body filter:** shown on the Parliament tab only: "All bodies", one chip per chamber that has sessions (`chamberLabel`), and "Not linked" for parliament sessions with no `session_records` row. On the Parliament tab the Type column becomes Body.
- **Row:** ▸/▾ toggle (only when it has clips) · title (with `lang`/`dir="auto"`) and a sub-line "YouTube · 33m 12s" / "Upload · 4m 36s" (`formatLength`; omitted while the length is unknown) · Type (or Body) · Added (date) · Where it is · Clips ("8 · 1 rendered", "1", "none yet", "—" before ready) · Go to links. Clicking the title opens the session where it is.
- **Where it is / row link:** processing → running label + " · N%" → `/s/[id]`; `awaiting_context` → "Context check: waiting for you" (purple, human-in-the-loop) → `/s/[id]`; ready with clips → "Prepare" → `/s/[id]/prepare`; ready without clips → "Briefing ready" → `/s/[id]`; failed → "Failed" (red, never the raw error) → `/s/[id]`.
- **Go to:** ready → Briefing, Prepare, Export (Prepare and Export shown dimmed, not links, when there are no clips); `awaiting_context` → Context; processing → Processing; failed → none.
- **Clips strip** (row expanded): up to 4 tiles, then a "+ N more" square (no arrow) that shows the rest in place. Tile: thumbnail (moment thumb, or a neutral block), "Clip n · 16:9" / "9:16" / "merged", length (`formatLength`), "Rendered" or "Not rendered", "Subtitles: de, en" when it has tracks. A tile links to `/s/[id]/prepare`.
- **Top bar:** "Sessions" link (to `/`) on every page except login; inside a session whose stage is `ready`, the Briefing / Prepare / Export step names are links (the current one stays bold text with `aria-current="step"`).
- The failed screen's "Start over" goes to `/new`.
- **Not in scope:** login, deleting sessions, the tree view (option C), changes to Prepare/Briefing/Export content.

## Global Constraints

- Follow `.claude/skills/digestor-ui/SKILL.md` (tokens, colours: purple = waiting for the human, red = failed, green = done; copy in `apps/web/messages/en.ts` via `t()`; never inline strings) and `.claude/skills/nextjs16-gotchas/SKILL.md` (DB reads inside `Suspense`, `await connection()`).
- `@digestor/core/server` only in server code; the client component gets plain data (no `Date` objects across the boundary: ISO strings).
- No "→" glyph in any new copy (owner's taste).
- Times: lengths via `formatLength` from `@digestor/core` (`packages/core/src/time.ts`); dates `Intl.DateTimeFormat("en", { day: "numeric", month: "short" })`.
- Filters live in the URL query (`type`, `body`, `status`, `q`, `clips=1`, `recent=1`) so a reload or shared link keeps them; unknown values are ignored.
- Never commit `.env`, `data/`, `node_modules`, `.pnpm-store`. Commit per task on the branch; merging to `main` needs the owner's word.
- Automated UI checks only on freshly seeded sessions (`seed-demo.ts`), never the owner's.

## Review Focus

1. A session still at `uploaded` with no profile, no duration and no clips renders a row (no "NaN", no crash) and counts under All and "processing now".
2. A video whose files were removed (`videoRemoved`) never counts as "clips not exported yet" (it can't render any more) and its row says so ("Video removed" in the sub-line).
3. Filter combinations that match nothing show an empty-result line with a "Clear filters" button, not a blank table; `?status=bogus` is ignored.
4. At 390 px the table becomes stacked rows with no horizontal page scroll; tap targets ≥ 32 px.
5. Titles in Cyrillic/German/Portuguese with accents are found by an accent-free search ("sessao" finds "Sessão").
